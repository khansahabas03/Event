# Akif & Raisa Fareen Wedding Invitation

A responsive React + Vite wedding invitation website using Tailwind CSS v4, Framer Motion, and Lucide icons.

## Run locally

1. Install Node.js (LTS).
2. Extract the ZIP and open a terminal in this project folder.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open the local URL shown by Vite.

To check a production build, run `npm run build`.

## Update details

Edit `src/data/weddingData.js` for names, dates, venues, family details, and story text. Images are in `src/assets/images/`.

## Included sections

- Animated invitation opening
- Couple hero section
- Live countdown to Nikah
- Haldi, Barat & Nikah, and Reception events
- Couple story timeline
- Photo gallery
- Family section
- Responsive mobile layout


## Typography

The design uses Playfair Display and Cormorant Garamond for editorial headings, Parisienne and Great Vibes for romantic script accents, DM Sans for readable interface text, and Amiri for Arabic text. Google Fonts requires an internet connection. A custom SVG favicon is included in `public/favicon.svg`.


## Audio playback note

The ambient soundtrack is generated by the browser and starts when a visitor clicks **Open Invitation**. Browsers block audible autoplay before a user gesture, so fully automatic sound on initial page load cannot be guaranteed. The floating music button can pause or resume playback.


## Music and creator credit

The built-in soundtrack is an original browser-synthesized Indian-romantic instrumental-inspired melody, not a copyrighted Bollywood song recording. It begins after the visitor clicks Open Invitation because browsers block sound before user interaction. The footer credits Shahbaz Khan and links to the supplied Instagram profile.
